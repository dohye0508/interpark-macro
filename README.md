# 🎫 인터파크 취켓팅 매크로 (Interpark Ticketing Macro)

[![Release](https://img.shields.io/github/v/release/dohye0508/interpark-macro?color=blue&label=Latest%20Release)](https://github.com/dohye0508/interpark-macro/releases)
[![Python](https://img.shields.io/badge/Python-3.11-yellow.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

파이썬(Tkinter & PyAutoGUI) 기반의 **인터파크 티켓 예매(취켓팅) 자동화 매크로**입니다.  
원하는 좌석 등급(포도알 픽셀 색상)을 실시간으로 감지하여, 찰나의 순간에 빠르게 좌석을 선점할 수 있도록 도와줍니다.

> 📦 **실행 파일(.exe) 다운로드**: Python 설치 없이 바로 실행하고 싶으신 경우, **[Github Releases 최신 버전](https://github.com/dohye0508/interpark-macro/releases)**에서 `.zip` 압축파일을 다운받아 실행하세요.

---

## ✨ 주요 기능 (Key Features)

- **🎨 사용자 친화적 GUI & 실시간 로그**:
  - 간결하고 직관적인 UI 레이아웃과 프로그램 내 실시간 통합 터미널 로그 콘솔 제공.
- **⚡ 실시간 좌석 색상 등록 & 삭제**:
  - `a` 키를 누르는 즉시 좌석(포도알) 색상이 등록됩니다.
  - 잘못 등록한 색상은 **색상 목록에서 더블 클릭**하여 즉시 삭제할 수 있습니다.
- **🎯 픽셀 기반 고속 좌석 탐지**:
  - 캡처 영역 내 픽셀을 초고속으로 탐지하여 지정한 등급의 좌석이 뜨는 즉시 클릭합니다.
- **🔄 자동 새로고침 & 결제 진행 연동**:
  - 새로고침 딜레이를 무작위(Random)로 부여하여 매크로 방지 시스템을 우회하고, 좌석 선점 즉시 '좌석선택완료' 버튼까지 자동으로 클릭합니다.
- **🛑 긴급 중지 단축키 지원**:
  - 매크로 동작 중 키보드 `;` 키를 누르면 즉시 안전하게 매크로가 정지됩니다.

## 🖥️ 프로그램 화면 구성

| 구 분 | 내 용 |
| :--- | :--- |
| **좌측 캔버스** | 캡처한 좌석 영역 썸네일을 실시간으로 미리보기로 표시합니다. |
| **우측 컨트롤 패널** | 영역 설정, 색상 추가, 새로고침/완료 좌표 등록, 매크로 시작 버튼 제공. |
| **하단 로그 창** | 좌표 등록 정보, 탐지 상태, 오류 메시지 및 예매 진행 상황을 실시간 출력. |

## 🚀 사용 방법 (Step-by-Step Guide)

프로그램을 실행한 후, 우측 버튼을 **위에서부터 순서대로** 누르며 세팅을 진행합니다.

### 1️⃣ 좌석 영역 선택하기
1. `좌석 영역 선택하기` 버튼 클릭.
2. 인터파크 좌석표 창의 **좌측 상단 모서리**에 마우스를 올리고 **`a`** 누름.
3. 좌석표 창의 **우측 하단 모서리**에 마우스를 올리고 **`b`** 누름.
4. 좌측 캔버스에 캡처된 좌석 영역이 제대로 표시되는지 확인.

### 2️⃣ 좌석 등급(색상) 선택하기
1. `좌석 등급 선택하기` 버튼 클릭.
2. 예매를 원하는 **좌석(포도알 색상)** 위에 마우스를 올리고 **`a`** 누름. (누르는 즉시 색상 리스트에 추가됨)
3. 💡 **색상 삭제**: 실수로 다른 색상을 찍은 경우, 오른쪽 **등록된 색상 목록**에서 해당 색상을 **더블 클릭**하면 지워집니다.
4. 등록을 완료했다면 **`c`**를 눌러 색상 선택 모드를 종료합니다.

### 3️⃣ 새로고침 좌표 가져오기
1. `좌석 새로고침 좌표 가져오기` 버튼 클릭.
2. 브라우저 내 '좌석 다시 선택(새로고침)' 버튼 위에 마우스를 올리고 **`a`** 누름.

### 4️⃣ 좌석 선택 완료 좌표 가져오기
1. `좌석 선택 완료 좌표 가져오기` 버튼 클릭.
2. 브라우저 우측 하단의 '좌석선택완료' 버튼 위에 마우스를 올리고 **`a`** 누름.

### 5️⃣ 매크로 시작 및 중지
1. 모든 좌표 설정 후 `매크로 시작` 버튼 클릭.
2. 매크로 동작을 중지하고 싶을 때는 키보드 **`;` (세미콜론)** 키를 누르거나 `매크로 중지` 버튼을 누릅니다.

## ⌨️ 단축키 요약 (Hotkey Reference)

| 단축키 | 기능 설명 |
| :---: | :--- |
| **`a`** | 좌석 영역 좌상단 / 좌석 색상 / 버튼 좌표 등록 |
| **`b`** | 좌석 영역 우하단 등록 |
| **`c`** | 좌석 색상 등록 모드 종료 |
| **`;`** | **매크로 즉시 정지 (긴급 중지)** |

## ⚙️ 상세 설정 (Configuration)

`main.py` 상단 변수를 직접 수정하여 동작 파라미터를 변경할 수 있습니다.

```python
NEED_SEAT_CNT = 1  # 예매할 좌석 수 (단일: 1, 연석: 2 등)
OFFSET = 20        # 좌석 클릭 시 클릭 영역 보정 픽셀 값
ALARM = False      # 예매 성공 시 알람 음원 재생 여부
```
